Class: BettingModelServer
  
  __init__(models_dir, project_id=None)
    - Load all trained models from directory
    - Cache in memory for fast inference
    - Initialize GCP BigQuery/Storage clients
    
  predict_game(sport, game_id, features, markets=['spread', 'total'])
    - Generate predictions for game across markets
    - Return confidence, edge (EV), rationale
    - Support spread, moneyline, total markets
    - Log predictions to BigQuery
    
  _calculate_edge(win_prob, decimal_odds)
    - Formula: (win_prob * decimal_odds) - 1
    - Breakeven at -110 = 53.8% win prob
    - Only recommend edge > 3%
    
  _explain_prediction(model, features, market)
    - Extract top 3 feature importances
    - Convert to natural language
    
  health_check()
    - Return model availability status

API EXAMPLES
================================================================================

Generate Picks:
  curl -X POST http://localhost:5000/api/generate-picks \
    -H "Content-Type: application/json" \
    -d '{"sport": "nba", "min_confidence": 0.60}'

Create Pick:
  curl -X POST http://localhost:5000/api/picks \
    -H "Authorization: Bearer <token>" \
    -H "Content-Type: application/json" \
    -d '{
      "sport": "nba",
      "event_id": "12345678",
      "bet_type": "spread",
      "selection": "home",
      "line": -5.5,
      "odds": -110,
      "stake": 100
    }'

Update Pick:
  curl -X PUT http://localhost:5000/api/picks/<pick_id> \
    -H "Authorization: Bearer <token>" \
    -H "Content-Type: application/json" \
    -d '{"status": "won", "result": true, "profit": 90.91}'

Delete Pick:
  curl -X DELETE http://localhost:5000/api/picks/<pick_id> \
    -H "Authorization: Bearer <token>"
